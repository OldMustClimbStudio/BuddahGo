Family/PostScript names changed to BuddahGo Solo CJK / BuddahGoSoloCJK.
The TMP asset has a static 2048px atlas baked from all 499 supported subset codepoints, with no OS-font dependency. Re-bake the atlas whenever changing the subset; do not reuse glyph-index caches from an older font file.
When adding translated UI strings, verify character coverage and regenerate the subset if needed.
