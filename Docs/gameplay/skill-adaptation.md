# 技能互相适配（后续任务）

一个技能的表现，要在其他技能造成的状态下也成立：巨人放禅定缓流、被转向反转命中的人正在巨大化、一念光明的黑幕里看得见谁的拖尾，等等。技能各自做完时只在正常状态下调过，这类组合要单独过一遍。用户 2026-11-03 定为后续任务，分成两部分：

- **通用**：每个技能的特效和玩法表现，在其他技能的状态下是否还对（遮挡、颜色、范围、时长、谁看得见）。
- **体型（巨大化 ×4 / 反噬 ×0.3）**：其他技能在巨人或缩小的角色身上怎么变。第一项已经做完（禅定缓流），做法和逐个插槽的现状见 [../vfx/giant.md](../vfx/giant.md)。

PR #63（`feat/mechanics-update`）合并后，把本文链进 `Docs/gameplay/README.md` 的技能设计部分，并和"缘起"组合（缘起 PR `feat/yuanqi` 里的 `yuanqi.md`）对照：缘起是技能之间有意设计的配合，本文处理的是任意两个技能同时生效时表现层要兼容。

|---|---|---|
