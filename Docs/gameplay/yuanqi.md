## 规则摘要（已定，完整版见 README §5.1）

- **触发**：一个技能正在生效时，另一个与它互有缘起的技能也进入生效（前摇结束、执行的那一刻），两招重叠的一瞬间触发。
- **顺序**：没有顺序规则，先放哪招都能触发。
- **一招同时满足几对**：只和生效最晚的那个搭档触发，一次只触发一对（已定，2026-11-07，见下面“缘起相关的规则”）。
- **技能联动**：每招按各自的机制结算，写了消耗的就结束；其他正在生效的技能状态（比如金身的体型）照样作用在缘起效果上（已定，2026-11-07，见下面“缘起相关的规则”）。
- **效果与收尾**：按每对的描述：触发时出现什么效果（瞬发一次，或持续一段）；之后哪招被消耗（剩余效果当场结束），哪招照常持续到自己结束。描述里没写消耗的，两招都照常持续。
- **先后决策**：被消耗的那招先放，可以先享受完它的效果，在它结束前让另一招生效；反过来，它一生效就被消耗。第二招有 1 秒前摇，要在先放那招结束前至少 1 秒请求。
- **全局技能的“生效中”**：一念光明按黑幕保持期 10 秒算，逆姻缘按反转的 10 秒算，都看施法者自己的窗口。

## 神足通

基本技能效果：持续时间内加速，可以突破速度上限。现值：持续 3 秒，前推力 +50、速度上限 +40（基础 50 / 80）；冷却 5 秒，执念 +300。

### 与禅定缓流（#2 禅足冰封）：已定

当与禅定缓流发生缘起效应时，加速与减速相合，将周围的空间瞬时膨胀。

- 名称：禅足冰封
- 主要效果：以自身为中心，对周围较大圆形范围内的敌方单位瞬间施加 N 秒禁锢。一次性生成，没有持续时间。
- 禁锢：完全定住，转向也不保留；身上已有的速度瞬间归零。禁锢期间什么都不能做：不能放技能、不能推掌，完全变成冰块。冰块本身的效果以后再做。
- 敌方单位：施法者以外的所有人，包括 AI 和训练木桩。
- 收尾：触发后两招都被消耗：禅定缓流和神足通的剩余效果全部结束，任一技能都不再持续。
- 参数：N（禁锢秒数）、范围半径。
- 范围随掌倍率（已定，2026-11-07）：实际半径 = R × 施法者触发那一刻的掌倍率，和如来神掌、#1 金身巨掌用同一个值（`PalmSizeRule`）：金身满体型 ×2（12 → 24 米），金身反噬缩到底 ×0.5（6 米），变大、缩小过程中线性过渡，平时 ×1。目标收集和地面冰面特效都按这个半径。配表不加新列。用户原话的要点：缓流和神足通按表被消耗、照样结束，但因为变大了，冰封范围也变大了，这就是技能联动。
- 视觉效果：周围地面瞬间结冰，受影响的对手冻结为冰块，禁锢结束后恢复。2026-11-06 先补了占位，同日换成正式特效第一版：半径 R 的冰面和裂纹 0.12 秒内铺开，每个被冻的人包进一块冰（用户选的 v4 冰体：每个晶面一个平的色调，同日从 v1.5 换来），解冻时化掉、掉碎冰；只用白 / 灰（[特效 README §2](../vfx/README.md) 的配色）。细节见 [特效文档](../vfx/yuanqi-frost-lock.md) 第 8 节，接口见 [缘起架构设计 §4.7](yuanqi-architecture.md)。被冻的人照旧动画停住、双手不转。

### 与法相金身（#4 金足破阵）：已定

当与法相金身发生缘起效应时，巨大的佛像一瞬间获得超级冲量，向前强力冲击突进。

- 名称：金足破阵
- 主要效果：神足通不再持续加速，而是一瞬间解除速度上限、获得巨大推力，向前弹射突进（像被人从后面猛推一下）。法相金身放大了体积和质量，突进中撞到其他玩家时，被撞者在碰撞瞬间额外受到 M 倍普通推掌的冲量。冲散他们的阵型。
- 突进手感：“刷”地一下突进。一下给一个很大的速度，然后按曲线快速回落到原来的速度上限。实现见 [缘起架构设计 §5.1](yuanqi-architecture.md)。
- 撞击：一次突进里，同一个人只会被撞一次，感觉是被大力弹开。冲量 = M × 普通推掌冲量（现值 100）。
- 收尾：神足通被消耗；法相金身持续到自己结束。
- 先后：先放金身，神足通一生效就变成突进；先放神足通，可以先享受加速，在它结束前让金身生效再突进。
- 参数：突进速度、回落时长与曲线、M。
- 视觉效果：2026-11-06 做了第一版插槽并接上缘起：触发那一刻从巨人身后喷出放大的神足通冲击波（后喷），同时在地上一笔画出一条朝车头方向的墨路，巨人顺着它冲出去，墨路留在原地 1.5 秒；施法者相机另有一次短 FOV 抖动。用户定（2026-11-06）：先按第一版交付，细节由用户自己在 VFXtests 里调（“放在 vfx test 里面 后续我来调整”）。默认值和还要调的项见 [特效文档](../vfx/yuanqi-giant-charge.md) 第 5 节。
- 弹开方向（Q9，已定）：沿碰撞方向往两边弹开，即从施法者指向被撞者的水平方向。
- 被缓流减速时（Q15，已定，2026-11-06）：接受现状。施法者放神足通后被敌人的缓流减速覆盖了加速，缘起照常消耗神足通、照常弹射，突进从减速后的上限起步。

### 与如来神掌（#1 金身巨掌）：已定

当与如来神掌发生缘起效应时，神掌随佛像一起变大。

- 名称：金身巨掌（原名“巨掌”）
- 主要效果：神掌随佛像变大，推力随之变大。这是持续关系：体型变小时，掌和推力也一起变小，不设上限。
- 神掌尺寸（已定，2026-11-06，取代“金身 ×4 时神掌也 ×4”）：普通状态下掌是原来的一半；金身时 ×2（回到原来的普通大小）；被金身反噬缩小时 ×0.5（原来的 1/4）。变大、缩小过程中按体型线性过渡。这条规则不分有没有缘起，蓄力掌和反噬弹幕都适用；配表是 `Skill/Push.sizeMultiplier`（0.5）和 `Skill/SkillEffectGiant.palmSizeMultiplier`（金身 2、反噬 0.5）。
- 推力（已定，2026-11-06）：缘起期间推力跟掌的尺寸倍率走，金身时 ×2（500 → 1000），不是体型的 ×4。
- 收尾：两招照常持续；任一招结束，神掌恢复原样。
- 参数：无单独参数，跟随体型。
- 视觉效果：不做，沿用神掌随体型缩放的现有表现（2026-11-06 用户定）。掌的尺寸、判定盒、墨手和开火动画本来就跟着掌倍率一起缩放（普通 ×0.5、金身 ×2），缘起新增的只是推力跟着掌倍率走（金身 ×2），不另画。

## 缘起相关的规则

- 一次重叠只触发一次；同一对要再触发，必须形成新的重叠（已定，2026-10-25）。
- 技能联动（已定，2026-11-07）：每个技能是单独的机制，各自结算。一对缘起写了消耗哪招，那招当场结束，“没了就是没了”；没被消耗、仍在生效的技能状态照样作用在缘起效果上。例子：先金身、再缓流、最后神足通，触发禅足冰封，缓流和神足通都结束，但金身的体型还在，所以冰封范围按掌倍率变大（见 #2）。同一次施法只被认领一次（见下一条）：冰封之后再放一次神足通，只剩金身能配，触发金足破阵。
- 一个技能生效时同时满足几对缘起，只触发其中搭档技能生效得最晚的那一对，其余几对这一次都不触发（已定，2026-11-07）。用户的例子：配装缓流 + 神足通 + 金身，先变大、再放禅定缓流、最后神足通生效，触发 #2 禅足冰封；先缓流、再变大、最后神足通，触发 #4 金足破阵。“生效”按技能状态板上的开始时刻比较，同一时刻按施放先后。AI 判断后手用同一条规则（`YuanqiPairTable.PickLatestPartner`、`AIYuanqiPlanner.TryGetFollowUp`）。这条规则不分对，同样适用于两对都不消耗这一招的情况：例如神掌 + 神足通都在生效时金身生效，只触发搭档较晚生效的 #1 或 #4，不会两个都触发（用户 2026-11-07 确认）。
- 被消耗的技能不返还冷却和执念（已定，2026-10-25）。
- 被禁锢打断前摇的施法，退还该槽的冷却（已定，2026-10-25，Q10 的补充）。已经判定为反噬的施法不被禁锢打断：冷却照常花掉，前摇结束时照常进入反噬惩罚（已定，2026-10-26），它的 `_anti` 变体也照常放出（已定，2026-10-31）。
- 本次施法本来会和正在生效的技能触发缘起，但掷出了反噬：缘起不触发；正在生效的那一招不被消耗，按普通版本持续到它自己结束（哪怕这对写了消耗）；本次技能只放出自己的 `_anti` 变体，外加 5 秒惩罚。反噬变体不进技能状态板，不能触发也不能参与缘起（已定，2026-10-31，见 [README §6.2](README.md)）。
- 缘起效果（如 #2 的禁锢）算不算控制、是否计入受害者的控制上限：仍待定。
