# Multiplayer Framework Integration

## Overview

This document describes the integration of the `BuddahGo-Multiplayer-Framework` repository into the main `BuddahGo` project via Git subtree merge, completed on `feature/Multiplayer-Framework`.

---

## Source Repository

| Item | Value |
|------|-------|
| Remote | `BuddahGo-Multiplayer-Framework` |
| URL | `https://github.com/OldMustClimbStudio/BuddahGo-Multiplayer-Framework.git` |
| Branch | `main` |
| Merge strategy | `git subtree` (staged under `MergedProject/`) |

---

## What Was Integrated

### Plugins — `Assets/Plugins/`

| Plugin | Purpose |
|--------|---------|
| `Facepunch.Steamworks/` | Steam SDK bindings for C# |
| `FishyFacepunch/` | FishNet transport layer over Steam |

### Scripts — `Assets/Scripts/`

| File | Location | Purpose |
|------|----------|---------|
| `GameNetworkManager.cs` | `Scripts/Network/` | Core FishNet network manager setup |
| `NetLog.cs` | `Scripts/Network/` | Network debug logging utility |
| `SteamLobbyManager.cs` | `Scripts/Network/` | Steam lobby create / join / leave |
| `DebugNetworkTester.cs` | `Scripts/Debug/` | In-editor network connection tester |
| `DebugLobbyTester.cs` | `Scripts/Testing/` | Steam lobby flow debug helper |

### Scenes — `Assets/Scenes/`

| Scene | Purpose |
|-------|---------|
| `SampleScene.unity` | Debug multiplayer test scene; use with `DebugNetworkTester` and `DebugLobbyTester` |

### FishNet Demos — `Assets/FishNet/Demos/`

Additional official FishNet demo scenes integrated from the framework repo:

| Demo | Scene | Notes |
|------|-------|-------|
| `Authenticator` | `Authenticator/Scenes/Authenticator.unity` | Password-based auth example |
| `Benchmarks` | `Benchmarks/NetworkTransform/Scenes/NetworkTransform Benchmark.unity` | NT stress test |
| `ColliderRollback` | `ColliderRollback/Scenes/ColliderRollbackDemo.unity` | Lag-compensated hit detection |
| `CustomSyncType` | — | Custom SyncVar pattern examples |
| `HashGrid` | `HashGrid/Scenes/HashGrid_Demo.unity` | Spatial hash AOI demo |
| `IntermediateLayer` | `IntermediateLayer/Scenes/IntermediateLayer.unity` | Data relay pattern |
| `Prediction` | `Prediction/CharacterController/` and `Prediction/Rigidbody/` | Client-side prediction |
| `SceneManager` | `SceneManager/Additive Scenes/` | Additive scene loading (5 scenes) |
| `SceneManager (Old Examples)` | `SceneManager (Old Examples)/Scenes/` | Legacy scene management (6 scenes) |

## What Was Intentionally Excluded

| Item | Reason |
|------|--------|
| `MergedProject/Assets/FishNet/` (core) | Identical version (4.6.20) already in main project |
| `MergedProject/Assets/Settings/` | Main project has a more complete URP settings set |
| `MergedProject/Assets/Scenes/SampleScene` (Settings profile) | Duplicate of main project's `Settings/SampleSceneProfile.asset` |
| `MergedProject/Assets/TutorialInfo/` | Unity boilerplate tutorial files |
| `MergedProject/Assets/Readme.asset` | Unity boilerplate |
| `MergedProject/ProjectSettings/` | Main project settings are newer; no changes needed |
| `MergedProject/.vscode/` | IDE-local config |
| `MergedProject/Packages/packages-lock.json` | Regenerated by Unity on open |

## Packages / manifest.json

One dependency version was upgraded during the merge:

| Package | Before | After |
|---------|--------|-------|
| `com.unity.collab-proxy` | 2.6.0 | 2.11.3 |

All other dependencies in `BuddahGo-Multiplayer-Framework` were already present in the main project at the same or newer version.

---

## DefaultPrefabObjects.asset

The framework repo's `DefaultPrefabObjects.asset` references **12 network-spawnable prefabs** (Steam transport, lobby objects, etc.) vs the main project's **3**. These have not been merged yet.

**Action required:** After validating the Steam/FishNet prefabs exist in the project, update `Assets/DefaultPrefabObjects.asset` in Unity Editor to register the additional spawnable prefabs from the framework.
