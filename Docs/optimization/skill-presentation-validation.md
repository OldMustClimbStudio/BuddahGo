# 技能表现修复：N6 / B11

## N6 反噬连发起点

48 例本机专项证实服务器与观察者分别从各自角色位置计算反噬连发起点。case 11 的 server z=182.537445、client z=174.201874，相差 8.335571；普通弹体已经使用服务器坐标。

服务器现在只计算一次 5 发起点、方向和尺寸，新增的 ObserversRpc 发送这些值；客户端用对应 SkillAction 中原有特效 prefab/progress 配置播放，原观察者入口保留 Feel 播放，避免重复生成视觉弹体。服务器命中创建、冲量、尺寸、时长、反向/自身命中/忽略地形配置都不改。旧 RPC 签名与声明顺序不改，新增 RPC 追加在 SkillExecutor 尾部；运行端应使用同版构建。所有序列化字段及资产值不变。

## B11 空特效为明确设计

用户确认 SlowTrap 反噬本就没有特效。只在反噬技能里对空白 vfxId 跳过播放，不新增美术，不改变定身、加速或全屏 Reflection 反馈。有效 id 和非空错误 id 的原有路径保留。

## N6 视觉起点取舍（F5）

反噬连发的视觉弹使用服务器一次规划的世界坐标，与 hitbox 起点一致。客户端施法者模型受插值和网络延迟影响，视觉弹可能与客户端看到的模型错开，量级约为车速 × 延迟。此处保留现有设计，不把坐标一致等同于高速观感已验收。高速行驶下的人工视觉验收与是否接受该偏移仍待团队确认，本轮未执行。
