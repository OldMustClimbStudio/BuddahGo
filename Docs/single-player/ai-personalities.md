## 博弈前提（修订）

原草案以"领先位置优势 vs 落后执念恢复优势"为核心博弈。按实际参数（追赶恢复 `0.01 × gap²`，gap 为整场完成度差），落后恢复只有在落后三分之一圈以上时才明显，近距离车群内几乎为零（初始执念已于 2026-10-04 由 1000 调为 0，不再有开局高风险期）。因此人格的博弈前提改为：

- **近距离博弈靠位置关系和状态窗口**：谁在谁前面、谁正在进弯、谁正被定身／反转／减速／缩小，这些是快照里直接可读的事实。
- **恢复优势是大差距下的追赶补偿**：决策读取真实的"当前反噬概率"，不按名次推断，不把恢复当成可以更频繁施法的许可；冷却、施法锁和搓招时间不变。
- **每场只有 6–9 次有意义的施法**（困难档），人格必须靠"何时放、对谁放、放哪个"被玩家看出来，而不是靠频率。
- 不通过故意减速、让位或改驾驶路线制造落后或接触。规划器不感知对手，也没有车车碰撞建模，所以任何"主动寻求碰撞"的描述都不可实现。

## 参数化人格模型

人格是一组配置，而不是五套代码。五个预设都只是下表参数的取值：

| 参数 | 含义 | 范围 |
|---|---|---|
| `loadout[3]` | 固定三技能与槽位顺序（槽 0／1 为三键搓招，槽 2 为四键） | 六个技能中选三个，经 Selectable 池校验 |
| `w[技能]` | 价值权重，决定同样机会下更偏好哪个技能 | 0–1.5 |
| `bias[局势]` | 局势偏置，按"领先且有追兵 / 领先无人 / 落后有目标 / 车群中 / 独自落后"放大或缩小价值 | 0–1.5 |
| `θ` | 耐心阈值，净值低于它不出手 | 0–0.6 |
| `τ` | 节奏常数，净值超过阈值后出手的平均等待时间 | 0.5–4 s |
| `target` | 目标偏好：前方最近 / 后方最近 / 车群中心 / 状态受损者优先 | 枚举 |
| `handsShots` | 每次掌形 buff 的发射上限 | 1–6 |

难度参数（风险权重、停手阈值、反应延迟、搓招失误率、瞄准容差、适应与感知受损）不在人格里。人格 ID 稳定（建议 `keeper`／`hunter`／`brawler`／`trickster`／`opportunist` 之类的配置键），显示名由用户命名后作为展示字段配置。

### 局势判定

快照中按进度差 `Δs` 判定，带 1.5 s 滞回，避免每帧跳变：

- **领先且有追兵**：后方最近对手 `Δs ≤ D_near` 且在接近。
- **领先无人**：后方 `Δs > D_near`，前方无人或前方 `Δs > D_far`。
- **落后有目标**：前方最近对手 `Δs ≤ D_far`。
- **车群中**：`|Δs| ≤ D_near` 的对手 ≥2。
- **独自落后**：前方 `Δs > D_far` 且后方无人或 `Δs > D_near`。

`D_near`、`D_far` 以赛道距离计，建议从缓流区长度与掌形有效命中距离推导，进入调校。

## 共享机会谓词

每个技能一个纯函数，输出机会分 `o`、目标与有效期；人格只改变权重，不改变谓词。

| 技能 | 机会分 `o` 的来源 | 有效期 | 备注 |
|---|---|---|---|
| 加速 | 前方 10 s 行程内的直道比例（曲率查表）× 自身未被定身 × 当前没有加速增益 | ≥3 s（看直道长度） | 弯前放加速会把增益浪费在撞墙上，所以直道比例是硬因子 |
| 缓流 | 后方最近对手 `0 < Δs ≤ D_trap`、正在接近、横向在同一车道带内；越近越接近 1 | ≈2–3 s | 区域挂在自己身上，只对跟车者有意义；无人在后方时恒为 0 |
| 巨大化 | `|Δs| ≤ D_contact` 的对手数量（≥2 为 1.0，1 个为 0.5）；或后方追兵 `Δs ≤ D_contact` 时的防守值 | ≈2 s | 碰撞结果不受 AI 控制；巨大化同时有 3.5× 前向力，也是短加速 |
| 掌形 | 前方最近对手 `0 < Δs ≤ D_hands`，所需 yaw 在可达范围内且能在 `t_aim` 内转到；越近、越正对越接近 1 | ≈2 s | 发射后命中取决于目标横向移动，没有制导；buff 期间每次按键都是发射 |
| 反转 | 未来 2 s 内将进入高曲率段的对手数（按各自进度与速度推算），按与自身的距离加权；× 自身未来 10 s 的直道比例（反噬会反转自己） | ≈2 s | 全场生效；可见反转仍在生效时 `o = 0` |
| 黑幕 | 与反转同类的"对手将进弯"计数，再加上车群密度 | ≈2 s | 单机下只影响真人屏幕；在 AI 感知受损状态实现前，对 AI 对手无效，人格携带它需用户知情 |
| 状态窗口（修饰项，非技能） | 前方目标处于 `IsInvertTurnActive`／`IsRooted`／`ScaleMultiplier<1`／负加速修饰符／刚减速 >X% 之一 | 等于该状态剩余时间 | 用于"机会主义"偏好：加速通过或掌形补刀；只读状态标志，不做行为推断 |

## 五个预设

代号描述行为，不是最终名字。每个预设列出配装与槽位（建议）、权重取向、领先／落后行为、弱点、与相近预设的区别，以及玩家能看出来的特征。槽位安排原则：招牌技能放三键槽，最少用的放四键槽。

### P1 守位型（`keeper`）

- **配装**：槽 0 缓流、槽 1 加速、槽 2 巨大化。
- **权重**：缓流 1.3、加速 1.0、巨大化 0.8；偏置：领先且有追兵 1.4、领先无人 0.5、落后有目标 0.9、车群 1.0、独自落后 1.0；目标偏好：后方最近；θ 0.25、τ 1.5 s。
- **领先时**：追兵接近时放缓流；车群里被贴身时用巨大化；前方直道且追兵在后放加速拉开。无人接近时价值被偏置压低，更愿意把冷却留着。
- **落后时**：直道加速追，入车群后才考虑巨大化／缓流；不对远处目标空放接触技能。
- **弱点**：拉开接触距离后只剩加速；它不会偏离原路线堵人。
- **玩家感受**：贴上去就会被拖住或撞开，甩开它之后它很安静。

### P2 追猎型（`hunter`）

- **配装**：槽 0 掌形、槽 1 加速、槽 2 反转。
- **权重**：掌形 1.3、加速 1.0、反转 0.9；偏置：落后有目标 1.4、领先且有追兵 0.8、领先无人 0.6、车群 1.0、独自落后 1.1；目标偏好：前方最近且进度相邻；θ 0.25、τ 1.2 s；`handsShots` 4。
- **领先时**：有直道则加速扩大间距；后方追兵紧迫且多人将进弯时考虑反转。没有可达射界时保留掌形，不为向后射击调转手部。
- **落后时**：目标太远先加速接近；进入射界后搓掌形并真实瞄准发射；目标即将进弯时反转的机会分升高。
- **弱点**：离开射界、错开接触时机就让它准备的攻击失效；它没有额外瞄准角度、弹速或命中保证；全局反转也会打到它不想打的人。
- **玩家感受**：它后面有人时，掌会一直朝着前面那辆车飞。

### P3 车群型（`brawler`，原"缠斗型"）

- **配装**：槽 0 巨大化、槽 1 掌形、槽 2 缓流。
- **权重**：巨大化 1.3、缓流 1.0、掌形 0.9；偏置：车群 1.5、领先且有追兵 1.0、落后有目标 0.9、领先无人 0.4、独自落后 0.4；目标偏好：车群中心；θ 0.30、τ 1.0 s；`handsShots` 3。
- **领先时**：只在真有人贴近时放缓流或巨大化；掌形只在射界内已有目标时使用。
- **落后时**：仍在车群中就优先能影响多人的巨大化／缓流，掌形处理可瞄准的单个对手。
- **弱点**：独自落在远处时三个技能都没有意义，它也不靠更快的驾驶补偿；这是真实的配装取舍，并且它**不会主动寻求碰撞**，碰撞只在赛车线重叠时发生。
- **与 P1 的区别**：P1 以"保住自己的位置"为触发（后方追兵），P3 以"周围有几辆车"为触发，不在乎自己是领先还是落后。
- **玩家感受**：正常跑线把大家聚到一起时，它最先变大。
- **替代方案**（供用户选择）：若希望第三个人格更可见，可改为"低耐心高频型"：θ 0.05、τ 0.5 s，配装不变。它会更频繁出手、更常反噬，行为差异更明显，但与 Q3 的难度谨慎规则叠加后在困难档仍受停手阈值约束。

### P4 干扰型（`trickster`）

- **配装**：槽 0 反转、槽 1 黑幕、槽 2 缓流。
- **权重**：反转 1.2、黑幕 1.2、缓流 0.8；偏置：落后有目标 1.2、领先且有追兵 1.1、车群 1.2、领先无人 0.7、独自落后 1.0；目标偏好：将进弯者；θ 0.30、τ 2.0 s。
- **领先时**：追兵接近、或多名对手将进入弯道时考虑黑幕或反转；贴身威胁用缓流。
- **落后时**：更愿意选择能影响远处对手的全局技能，争取让前方失误产生追赶空间。
- **边界**：普通黑幕中施法者能看边线，反噬时对调；AI 不免疫黑幕，受损时按感知受损状态降低驾驶与决策质量。可见的全局效果仍在生效时不再叠加。
- **弱点**：没有直接加速工具；全局干扰同样帮到其他落后者；`reverseturn` 当前执念增益为 0，使它的反转几乎没有执念代价，这一点待用户确认是否有意。
- **玩家感受**：它不一定在你眼前，但你进弯时方向突然反了、屏幕突然黑了，多半是它。

### P5 机会型（`opportunist`，原"收割型"）

- **配装**：槽 0 加速、槽 1 掌形、槽 2 黑幕。
- **权重**：加速 1.2、掌形 1.0、黑幕 0.8；偏置：落后有目标 1.2、领先且有追兵 1.0、领先无人 0.8、车群 1.0、独自落后 1.0；目标偏好：**状态受损者优先**；状态窗口修饰项 ×1.6；θ 0.35、τ 1.5 s；`handsShots` 2。
- **领先时**：追兵正处于反转／定身／缩小／减速状态时，优先用直道加速巩固间距，而不是再补控制；只有新的实际机会才用黑幕或掌形。
- **落后时**：前方目标处于受损状态是高价值窗口，优先加速通过或掌形补刀；拥挤且多人将进弯时也会主动用黑幕，不无限等待。
- **与 P2 的区别**：同样的前车稳定行驶时，P2 会准备掌形，P5 因阈值更高更可能等；前车已被别人打歪时，P5 的状态窗口修饰项让它立刻出手，而 P2 没有这项加成。区别完全来自状态标志，不依赖"识别失误"的行为推断。
- **弱点**：比赛平稳、无人受损时它出手最少；节奏抽样保证它不会整场不放，但次数会少于其他人格。
- **玩家感受**：你刚被别人搞到、速度一掉，它就从后面冲上来。

## 所有人格共享的规则

1. **同难度、同谨慎规则。** 人格通过配装、权重、偏置与阈值区分；风险权重与停手阈值由难度决定。人格的 θ 是"值不值得"，不是"敢不敢"，不能把 θ 调低来绕开困难档的风险规则。
2. **领先和落后会动态变化。** 局势判定带滞回，以真实进度差和附近竞争为依据。
3. **不把恢复当作无限施法。** 恢复只降低执念；冷却、施法锁和逐键搓招时间仍然限制频率。反噬不能主动选择、重抽或预知。
4. **技能不会同时生效。** 施法锁覆盖效果时长，唯一例外是掌形 buff 的后 5 s（可在瞄准结束后开始下一次搓招，按键会发射蓄力掌）；设计不描述任何连招。
5. **动作承诺。** 选定技能后逐键搓招，期间不换槽；掌形 buff 期间由瞄准器真实产生左右键与推掌。
6. **驾驶与公平性。** 不按人格改转向、速度上限或碰撞规则，不故意落后套利，不专门针对真人；读取的都是权威状态并带延迟与噪声；不读他人冷却与抽签。
7. **身份与命名分开。** 以稳定人格 ID 配置技能和参数，最终名字只是展示字段；用户改名不改行为。

## 重开与分配（2026-10-03 用户确认）

- 当前产品单机暂定六人：玩家 + 五个人格，五个预设全部出场，按稳定 ID 与显示名绑定。
- “再来一局”沿用人格、名字和固定三槽，局内随机状态随新角色独立初始化。
- 诊断工具仍允许较少 AI，按配置顺序取前 N 个；这不是产品人数选项或随机抽取策略。
- 最终名字由用户另定；当前使用清晰的 P1–P5 行为占位名。普通风险与其他建议数值继续配置化，不因已开工而变成已确认数值。

## 设计验证关注点

- **区分度（诊断指标，非机械门槛）**：同难度下多场模拟后，按人格统计施法在（局势 × 目标状态 × 技能）上的分布；任意两个人格至少在一个单元格上差异明显。若两个人格的分布几乎重合，说明参数或谓词设计失败，而不是靠改名掩盖。
- **同一人格从领先变落后、从落后回领先时**，选择随局势改变，但技能偏好仍可辨认。
- **节奏**：困难档每场施法量级约 6–12 次（实测 4–12）；简单档可以更多但反噬比例高。偏离这个量级先查执念读取与风险公式。
- **大差距与小差距的恢复分开观察**，用执念和当前反噬概率验证，不按名次推断。
- **五 AI 比赛**中检查搓招可见、手部动作可见、请求与实际效果、反噬后的恢复、完赛／DNF、重开和返回清理；不以施法次数代替人格有效或整场通过。
- **重点**：P3 脱离车群时的无作为是否可接受；P4 多车同时全局干扰的可玩性（交错与"可见即不叠加"是否足够）；P5 的状态窗口是否被玩家感知为"趁火打劫"。

本文件只提出五个人格的候选设计。最终名字由用户确定；配装／槽位、普通难度谨慎程度、固定人格的重开规则、黑幕感知受损是否纳入范围与全部数值尚未完成最终确认。当前不执行生产代码修改或 Unity 运行。
