### 六技能看点

| 技能 | 普通效果 | 遇到反噬时 |
|---|---|---|
| 神足通 | 加速、原粒子和拖尾出现，到期恢复并消失 | 自身减速，到期恢复 |
| 如来神掌 | buff 内再按 W 推掌，能看到蓄力、金色掌形飞行及消失；反复发射不留残影 | 多掌出现、飞行并消失；特别反馈是否看得清完整掌形 |
| 禅定缓流 | 陷阱特效出现并到期消失，自己不被普通陷阱减速 | 自身短暂定身后加速，再恢复 |
| 法相金身 | 变大后恢复正常体型 | 缩小后恢复 |
| 逆因缘 | 0 AI 时没有对手可反转，不应反转自己 | 自身转向反转后恢复，重点看手感 |
| 一念光明 | 施法者的边缘画面效果出现，到期恢复 | 施法者无边缘的画面版本，到期恢复 |

同时看技能释放和反噬爆发是否清晰、自然。反噬受现有概率影响；没触发就记“未看到”，不必为补清单反复刷。0 AI 无法验证对手命中、减速、反转或受害者画面，这些保持未验证，不要求用户补做对战。
