# 菜单资源表

配套规范：[style-guide.md](style-guide.md)。生成素材的提示词、处理脚本和验收标准见 [asset-generation-brief.md](asset-generation-brief.md)。通用要求见规范第 11 节：透明底 PNG；笔墨类画成纯白；按 1080p 显示尺寸的 2 倍出图；只用自绘或有授权的素材。
交付方式：文件交给开发后，由开发放进 `Assets/UI/MainMenu/`，并更新下表的"状态"一列。
笔墨类也可以交**白纸黑墨**的原图（纯白背景、黑色墨迹、不要阴影和纸张透视）：开发会转成"白色墨迹 + 透明底"，墨的浓淡保留为透明度。

**状态说明**：待提供 → 已提供 → 已接入。"占位中"表示现在游戏里用的是程序生成的临时版本；"不需要"表示这一项不做。
