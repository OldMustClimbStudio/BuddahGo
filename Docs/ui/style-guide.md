# 佛陀竞速 UI 风格规范（v1.0 草案，2026-11-06）

适用范围：主菜单（神社场景 `MenuEnvironmentSetting`）及之后所有菜单类界面。局内 HUD 沿用同一套颜色、字体和笔墨元素。
配套文件：[asset-list.md](asset-list.md)（资源表，交付和接入状态都记在那里）。
来源：视觉语言 v0.2「一笔」、参考作品（对马岛之魂、GRIS、ABZÛ）的分析，以及 2026-11-06 的 UIUX 审视。

目标品质：**可以对外发布**（Steam 试玩版和正式版）。

---

## 1. 核心原则

1. **场景就是背景。** 3D 神社一直可见，UI 只是浮在上面的几笔墨。不用整块的不透明面板；需要可读性时，用从屏幕边缘开始的渐变压暗。
2. **一笔。** 底部一条细墨线贯穿全屏，是菜单的基线，也是"赛道"。选中某一项，就是墨跑到那里停下。
3. **圆相即一圈。** 圆相只用来表示"进度、数量、一圈"（加载、倒数、人数、槽位），不当装饰随便用。
4. **克制。** 每屏最多一个强调色元素（朱砂）；每页只用一种选中记号；能不加的元素都不加。
5. **一致高于好看。** 同一种用途永远用同一种元素、同一个尺寸、同一种动效。不确定时，照抄已经定型的页面。

## 2. 色彩

| 名称 | 值 | 用途 |
|---|---|---|
| 宣纸白 | `#F4EFE6` | 所有文字、笔墨元素（素材画成纯白，程序里染成这个色） |
| 浓墨 | `#1E1A18` | 宣纸签上的字、反白字 |
| 暗化底 | `#0A0808` | 渐变压暗、遮罩 |
| 朱砂 | `#B8352A` | 选中点、就绪状态、印章、警示（例如"需要重启"） |

**文字透明度**（叠在已压暗的场景上）：
- 选中或主要：1.0
- 次要、未选中：0.65（**最低不低于 0.6**）
- 不可用：0.3，并且必须配一句说明为什么不可用

**压暗强度**（UI 所在的那一侧）：边缘 0.85 → 0 渐变，覆盖屏幕的 35–60%。整屏遮罩最多 0.2。

**禁止**：金色、彩色渐变、发光描边、霓虹、纯黑实心大面板（弹窗和设置页也一样，用渐变）。

## 3. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 书法（游戏名、技能名、倒数、皮肤名） | 手写书法 PNG（同一位书写者的笔迹） | 不用字体文件生成，避免笔迹不统一 |
| 正文和界面 | Noto Serif SC（OFL 授权） | 正文用 Regular；以后如有需要可加 Light |
| 西文和数字 | 同上 | 西文用大写，字距按"宽"那一档 |

**字号体系**（1080p 下的像素；其他分辨率等比缩放）：

| 级别 | 字号 | 用途 |
|---|---|---|
| T1 | 30 | 页面标题（设置、道场、技能……） |
| T2 | 26 | 选中的菜单项、列表选中行 |
| T3 | 22 | 菜单项、列表行、按钮文字 |
| T4 | 18 | 说明、描述、状态 |
| T5 | 16 | 按键提示、脚注（**全游戏最小字号**） |

**字距**只用两档：标题和菜单项 0.25em（"宽"），正文和说明 0.08em（"常规"）。
**标点不加字距**：句号、逗号前后不能被拉开；带标点的句子一律用"常规"字距。

## 4. 版式

- 参考分辨率 1920×1080。
- **安全区**：左右各 96px，上下各 54px，任何文字不得出界。
- 用锚点分区，不写死整屏坐标：左上（页面标题）、左侧（内容列）、底部（基线菜单）、右下（按键提示栏）。
- 支持 16:9、16:10、21:9。超宽屏时，内容列和标题跟随左边缘，不拉伸。

**固定位置**

| 元素 | 位置 |
|---|---|
| 页面标题 | 左上，距安全区左边 24px；标题下一条细线，长 450 |
| 内容列 | 左侧，起点 x = 120，宽 680 |
| 基线菜单 | 底部，基线距底边约 100px |
| 按键提示栏 | 右下角，贴安全区；所有页面统一在这里 |
| 场景标注 | 跟随 3D 物体，一条引线加两行字（名称 T4、动作提示 T5） |

**对齐规则**（参考对马岛之魂、ABZÛ 的列表和 GRIS、对马岛难度选择的居中构图）：
- **左对齐用一条线**：标题、副标题、页签、列表、细线、说明的左边都落在 x = 120。书法图片按墨迹对齐，不按图片边框对齐（图片自带的留白要扣掉）。
- **记号挂在线外**：朱砂点、选中三角放在左边线外侧（约 x = 104），文字不为它缩进。
- **列表两端对齐**：名称贴左线，数值贴右线，上下细线的两端就是这两条线（设置页 120–600）。
- **左右对称**：横贯全屏的页眉线和底栏，右边线和左边线对称（120 ↔ 1800）；按键提示栏贴安全区右下角（1824, 1026）。
- **单一焦点居中**：只看一样东西时（标题画面、细看绘马、确认弹窗），名称、正文、附注都沿同一条中轴居中，不和左对齐混用。
- **导航居中**：主页底栏的菜单项作为一组，在屏幕上水平居中。
- **提示跟着所属的内容**：按键提示都放在同一条底线上（y = 1026）。整页通用的提示贴右下角；只属于某一列的提示，和那一列对齐（居中的列就沿中轴居中，左对齐的列就对齐它的左线），不要从内容旁边突出去。

**页面模板**（新页面先从这几种里选）：
1. **主页型**：只有基线菜单，加左上角的小标题。
2. **侧栏型**：内容在左侧列，左侧渐变压暗（设置、技能搓招、皮肤、殿门）。
3. **场景标注型**：标签直接贴在 3D 物体上（房间席位、本殿、绘马）。
4. **弹窗型**：右侧（或居中）渐变压暗，两条毛边细线夹住正文，下面是宣纸签按钮。

## 5. 图形元素

只允许下面几种元素，每种的用途是固定的：

| 元素 | 用途 | 不要用来 |
|---|---|---|
| 毛边细线 | 基线、分隔线、标题下划线、引线 | 做边框、画框 |
| 选中墨线 | 当前选中项（基线上跑动、页签下方） | 做装饰 |
| 朱砂点 | 选中光标、就绪状态 | 同屏出现两个以上 |
| 粗圆相 | 仪式性的时刻：标题、开局倒数 | 放在列表或按钮里 |
| 细圆相 | 功能性：加载、槽位、人数进度、悬停时圈出 3D 物体 | 当图标的背景 |
| 宣纸签 | 确认类按钮（出发、确定、装配）；每屏最多一个 | 普通菜单项 |
| 短墨刷衬底 | 按钮悬停、主页选中项的底衬 | 和选中墨线同时用在同一项上 |
| 印章 | 只在游戏标题旁 | 其他任何地方 |

## 6. 状态

| 状态 | 表现 |
|---|---|
| 默认 | T3，透明度 0.65 |
| 悬停或键盘焦点 | 透明度 1.0，上浮 6–10px，字号升到 T2，前面出现朱砂点或墨线 |
| 按下 | 墨线快速扩展，字往下压 2px，并播放确认声 |
| 不可用 | 透明度 0.3，不能聚焦；下方用 T5 写明原因 |
| 已选中（例如当前页签、当前皮肤） | 下方常驻选中墨线 |

键盘或手柄操作时，焦点不能丢失；鼠标要移动超过 8px 才接管焦点。

## 7. 动效

**时长只用三档**：快 0.15 秒（悬停、状态切换）、标准 0.3 秒（页面元素进出）、慢 0.6 秒（圆相描绘、标题出现）。

**缓动只用两条**：入场用 ease-out（cubic），退场用 ease-in（quad）。

**顺序**：
- 切换页面时：UI 先退场 → 镜头移动 → 镜头停稳后 UI 再入场。UI 和镜头不同时剧烈运动。
- 列表依次入场，每项间隔 35ms。

**签名动效**（所有页面共用同一套实现）：
- 墨线跑动：选中项改变时，墨线沿基线流动过去，收笔处的飞白跟随。
- 圆相描绘：从起笔处按笔画方向画出，时长 0.6 秒。
- 宣纸签：出现时轻微展开。

每帧动画步长要设上限（单帧最多推进 0.1 秒），卡顿时动画放慢，但不跳过。

## 8. 交互与按键

> 待定：支持哪些设备（建议：键鼠 + 手柄）。下表按建议值写。

| 动作 | 键盘 | 鼠标 | 手柄 |
|---|---|---|---|
| 移动焦点 | 方向键（W/A/S/D 同效） | 悬停 | 左摇杆或十字键 |
| 确认 | Enter / 空格 | 左键 | A（PS：✕） |
| 返回 | Esc | 右键 | B（PS：○） |
| 切换页签或分类 | Q / E | 点页签 | LB / RB |
| 恢复默认 | R | 点提示栏 | Y（PS：△） |

**规则**：
- 所有页面只能用这张表里的键，不另外定义。
- "返回"永远回到上一层；在主页按"返回"会弹出"离开游戏"确认。
- 按键提示栏显示当前页可用的动作，接上手柄时自动换成对应手柄的图标。

## 9. 声音

> 待定：音效来源（建议：先用授权音效库）。

所有界面音效都走"音效"音量通道（`AudioChannelVolume`，通道选 Sfx）。

| 事件 | 声音性格 |
|---|---|
| 焦点移动 | 很轻的木鱼或拍子木 |
| 确认 | 磬或小铃 |
| 返回或取消 | 纸张摩擦 |
| 墨线跑动 | 极轻的毛笔擦纸声 |
| 不可用或错误 | 低沉的木声 |
| 开局倒数 | 每一下钟声，最后一下更重 |

音量要克制，不能盖过环境声。同一个事件在 0.05 秒内连续触发时只播一次。

## 10. 文案

- 用词统一：修行（单人）、道场（联机）、修行者（玩家）、施展（使用技能）。新词先加进术语表（`GLOSSARY.md`）。
- 按钮是动词，2–4 个字：出发、装配、离开。
- 提示一句话说完，句末不加感叹号。
- 所有文案从文案表读取（`UI/Text`），不在代码里写死。
  > 待定：是否支持英文（建议：支持；先把文案迁到表里，翻译之后再补）。

## 11. 美术资源制作规范

完整清单和交付状态见 [asset-list.md](asset-list.md)。
- PNG，透明底，sRGB；笔墨类画成纯白，深浅只用透明度表达。
- 按 1080p 显示尺寸的 2 倍出图。
- 保留真实的飞白和毛边。
- 长条元素拆成"起笔 / 可平铺中段 / 收笔"三段；圆相附起笔方向草图。
- 只用自绘或有商用授权的素材，授权文件一起交付。
