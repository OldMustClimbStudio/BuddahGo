# 反作用色板：受击与反噬的红色

整理日期 2026-10-29。配色原则见 [README 第 2 节](README.md#2-视觉方向已定2026-10-28-晚第三次改写)：

- **正向释放**用仪玄色板（[yixuan-palette.md](yixuan-palette.md)）。
- **反作用**用红色系。反作用指被别人的技能命中的受击，以及所有 `_Anti` 反噬。

仪玄色板取自外部参考。这一份取自用户手调的 `VFX_Reverse_Hit`（转向反转的受击，`Assets/VFX/转向反转/Hit/`），把它当作红色系的基准。本文只做整理和建议，不改资产。用户以后重调 `VFX_Reverse_Hit`，或做出新的反作用基准时，按第 2 节的方法重取。

## 1. 结论：反作用配色的配方

1. **三色分工：墨是底，红是雾，白是唯一的光。**
   - 墨占画面最大。
   - 红是一层 Alpha 混合的雾，把底色染红、压暗，自己不发光。
   - 发光的只有很小的白点和白符。
   - 对照仪玄色板：那边金是加色的光，从墨里透出来；这边红不是光，而是"染"。
2. **红集中在暗部。** 比赛截图里的红色像素，68% 的亮度在 V12–30（`#30110E`），25% 在 V30–50（`#622021`），7% 在 V50–70（`#903B34`），V>70 几乎没有（第 4 节）。观感是暗血红，不是亮红。
3. **红只有一个色相。** 所有红都在 H355–6，只靠明度和透明度分层：亮红雾 `#FF1010` → 血红烟 `#950000` → 暗血红 `#6F0000` → 屏幕上最深处的 `#30110E`。不往橙或品红偏。橙红 `#FA7030` 只出现在一个不确定是否可见的层上（第 3 节）。
4. **墨用纯黑 `#000000`。** 仪玄的墨带色相（暖橄榄、玄青），这里的墨全是中性纯黑。唯一带色相的暗色是黑火星 `#080416`（偏蓝紫，几乎看不出）。
5. **白只做点和符。**
   - 加色白点（`Flecks`、`Glowdot`），尺寸 0.01–0.03。
   - 一个半透明白阴阳符（α≈0.53）。
   - 一个白色 Fresnel 的折射泡。
   - 大面积的白不出现。
6. **灰只有一处**：阴阳冲击波环，`#3C3C3C` 经包的三色映射（白 / `#C3C3C3` / 黑）后呈中灰。烟本身的颜色随寿命变淡：生命周期颜色 `#CFCFCF` → `#767676`，乘在起始色上。
7. **在我们的沙地上可读。** 沙地是 H41 的暖黄（`#BBAC8B`）。红和它差约 40°，暗红比沙暗得多，所以色相、亮度都和沙地有对比。仪玄的中间调金在沙地上会消失（yixuan-palette 第 8 节），红没有这个问题。

## 2. 来源与方法

- **逐层取值**：
  - 用 MCP 加载 `VFX_Reverse_Hit.prefab`，读每个粒子系统的起始颜色、生命周期颜色，以及材质的混合方式、三色映射和 Fresnel。
  - 材质大多关掉了三色映射（`_USERAMP=0`），所以颜色基本就是粒子颜色乘贴图。
  - 屏幕上的近似值 = 起始色 × 生命周期颜色。
- **画面实测**：
  - 素材是 2026-10-29 比赛里转向反转命中时的 5 张截图（960×540，设计会话 scratchpad `revshots/layerhit_*.jpg`，不进仓库）。
  - 只统计 H<16° 或 >342°、S>45%、V>12% 的像素。
  - 这几张截图里同时有禅定缓流的黑色区域，黑的面积不代表受击本身，所以第 4 节只统计红。

| 红色像素的亮度段 | 占红色像素 | 中位色 | 说明 |

- 橙红像素（H16–32）只占 0.8%，中位 `#A1663E`，可能是 `#FA7030` 那层，也可能是红雾边缘和沙地混出来的，分不开。

## 5. 色板：做反作用插槽时用的值

| 角色 | 值 | 混合 | 用法 |
|---|---|---|---|
| 墨 | `#000000` | Alpha | 烟、墨冲击波、墨痕、黑雾；面积最大 |
| 血红烟 | 起始色 `#950000`，乘生命周期颜色 `#CFCFCF` → `#767676` | Alpha，α 1 | 红的主体，尺寸比墨烟小或相同 |
| 暗血红烟 | 起始色 `#6F0000`，α0.36 | Alpha | 大而淡的外层红 |
| 红雾 | `#FF1010`，峰值 α≤0.55，淡入快（约 9% 寿命） | Alpha | 软雾片，把底色染红；**不要改成加色**，加色会变成发光的亮红，偏离基准 |
| 中灰 | `#3C3C3C`，或三色映射 白 / `#C3C3C3` / 黑 | Alpha | 冲击波环之类的结构线，少用 |
| 白峰值 | `#FFFFFF` | 加色 | 只用于尺寸 ≤0.03 的点和闪烁 |
| 白符 | `#FFFFFF` α≈0.5 | Alpha | 阴阳符之类的符号，半透明 |
| 黑火星 | `#080416` | Alpha | 小碎屑 |
| 橙红（待定） | `#FA7030` | — | 基准里是否可见未确认；新插槽先不用，等用户定 |

**用包的三色映射时**（UberFXSG，`_USERAMP=1`），以下是候选值，未经用户确认：

| 层 | 映射目标 | Lows | Middles | Highs |
|---|---|---|---|---|
| 红烟 | 墨 → 血红 | `#000000` | `#6F0000` | `#950000` |
| 红雾 | 血红 → 亮红 | `#6F0000` | `#950000` | `#FF1010` |

两种映射都不给白，白留给加色的点。

## 6. 和仪玄色板的对照

| 项 | 正向（仪玄） | 反作用（本文） |
|---|---|---|
| 墨 | 带色相：暖橄榄 `#1C1C18`、玄青 `#111A19` | 纯黑 `#000000` |
| 光 | 金，加色，一条明度阶梯 | 没有彩色的光；红是 Alpha 混合的雾 |
| 峰值 | 白，释放爆闪那几帧大面积 | 白，只有小点，不爆闪 |
| 结构 | 外黑内亮：光从墨里透出来 | 墨和红雾叠在一起，整体压暗 |
| 饱和度 | 面积越大越淡，主金 S≈50% | 红 S 64–78%，比金饱和；靠暗和透明来压 |
| 沙地上 | 中间调的金会消失 | 暗红和沙地对比足 |

一个插槽只属于一边（README 第 2 节）。把正向插槽改成反噬版本时，按下面的方式替换：

- 金和暖光的加色层 → 红雾（Alpha，`#FF1010`，α≤0.55），或者直接去掉；
- 暖墨 → 纯黑；
- 灰烟 → 血红烟或暗血红烟；
- 白峰值保留，但缩小成点，不做爆闪。
